# HTML Email Portfolio

A collection of HTML email projects created to demonstrate my HTML email development skills.

## Projects

### Hyrule Travel Agency Newsletter

#### About the Project

Hyrule Travel Agency is a fictional HTML email newsletter created to showcase my HTML email development skills.

The project demonstrates responsive email layout techniques using HTML tables and CSS, with a focus on readability, accessibility, and compatibility with email clients.

All businesses, locations, and characters featured in the newsletter are fictional. The photographs are representative stock images used for illustrative purposes.

### Zora's Fabric Ltd. Promotional Email

#### About the Project

Zora's Fabric Ltd. is a fictional retailer featured in a promotional HTML email created to demonstrate email development techniques for a retail marketing campaign.

The project features a responsive product layout, a promotional call-to-action button with Outlook-specific VML markup, hidden preheader text, and a footer containing business address and unsubscribe placeholders.

The company and product are fictional. The product image is an original illustrative image created for this portfolio project.
